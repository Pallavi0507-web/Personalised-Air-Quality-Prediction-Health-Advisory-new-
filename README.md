# Personalised Air Quality Prediction & Health Advisory  The **Personalised Air Quality Prediction & Health Advisory** is a machine learning-based project developed using Python and Google Colab. The main objective is to analyse air-quality data and estimate air pollution levels using regression algorithms.  The project uses an uploaded air-quality dataset containing relevant environmental parameters. It performs data preprocessing, handles missing values, removes duplicate records, and applies exploratory data analysis to understand patterns and relationships within the dataset.  Three machine learning regression algorithms are implemented: Linear Regression, Decision Tree Regression, and Random Forest Regression. Their performance is compared using evaluation metrics such as Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and R² score.  In addition to prediction, the project demonstrates a personalised advisory system that provides general air-quality guidance based on the pollution category, selected outdoor activity, and sensitivity preference.  The overall goal is to demonstrate how machine learning can support air-quality analysis and help individuals make more informed decisions about outdoor activities.
